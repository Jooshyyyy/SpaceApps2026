Implementation assumptions: existing web controls remain public, like the web itself; the device-only endpoint requires an independent secret. One device, one service instance, existing in-memory state semantics; retain USB fallback. Do not change the human's prototipo/README.md edit. No actual Render deployment or firmware flashing is authorized/possible without user credentials/hardware.
Contract: endpoint /reloj/ws on the public HTTP port; device supplies Authorization: Bearer <WATCH_TOKEN> at upgrade (no URL tokens); text messages preserve existing $W,... newline server->device and $B,<button> newline device->server. Reject malformed/oversized input, browser Origin on the device endpoint, and unauthenticated clients. One active watch; reject a second authenticated connection rather than silently stealing ownership. Ping/pong, bounded sends and disconnect cleanup; firmware certificate verification and reconnect. Preserve existing /w, /estado, /reloj and event polling contracts. Heavy source downloads/ingestion must never happen on ordinary web startup; deployment can consume separately prepared processed layers.
